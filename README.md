## The joke

> My Escape key is worn smooth — it's the only thing in the office that actually lets you leave.

## How it works

`main.ts` writes exactly one line — the joke above — to `/output/entry.txt`.
It is deterministic: the same line on every run. The line is 94 characters,
inside the competition's 1–200 character gate.

Run it with Node 22 or later:

```sh
node main.ts
cat /output/entry.txt
```
